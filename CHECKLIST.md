## 1. Вёрстка на всех размерах экрана

Проверено на 5 контрольных ширинах (360 / 768 портрет / 1024 альбомная / 1440 / 1920px) — нигде нет горизонтальной прокрутки, ничего не обрезается и не наезжает.

Перепроверить самому: `npm run build && npm start`, затем `node scripts/verify.mjs` (сервер должен быть запущен на порту 3411).

## 3. Единственный оставшийся пункт — контраст текста

**Это решение за тобой, я не стал его менять сам.** На нескольких страницах (Обо мне, Навыки, страница проекта) Lighthouse отмечает, что светло-серый текст (метки полей, пункты навигации, индекс проекта) не проходит контраст WCAG AA на белом фоне:

- `#B3B3B3` (метки полей) — контраст 2.1:1, нужно 4.5:1
- `#B2B2B2` (навигация, prev/next) — контраст 2.1:1
- `#8E8E8E` (приглушённый текст) — контраст 3.3:1

Это не баг — именно такую светло-серую палитру задал сам дизайн («четырёхступенчатая серая лестница» из readme дизайн-системы), это часть визуального стиля. Но формально она не проходит стандарт доступности для слабовидящих пользователей.

**Варианты:**
- Оставить как есть — это осознанный визуальный выбор автора дизайна.
- Затемнить конкретные оттенки (например `#B3B3B3` → `~#767676` дало бы нужный контраст) — но это уже правки бренд-палитры, не мне их вносить без твоего решения.

Скажи, если хочешь — я подготовлю вариант с более контрастными оттенками на сравнение.

## 4. Изображения и медиа

- Все фото проектов и портрет — через `next/image` (автоматический webp/avif, ленивая загрузка вне экрана, точный размер под устройство).
- Постер фонового видео на главной сжат (1.3МБ → 135КБ) и подгружается адаптивно.
- Видео на главной уважает системную настройку «уменьшить анимацию» — вместо автовоспроизведения показывает статичный кадр.

## 5. Клавиатурная доступность

- Все интерактивные элементы (ссылки, кнопки, узлы графа навыков) видно фокус-рамку при навигации с клавиатуры (Tab).
- Мобильное меню закрывается по Esc, фокус возвращается на кнопку-гамбургер.
- Граф навыков полностью управляем с клавиатуры (Tab между узлами, Enter/Space — выбрать).

## Перед тем как отправить ссылку кому-то

1. Настроить Sanity и один раз запустить `npm run seed` (см. README.md) — иначе сайт покажет резервный текст вместо твоего реального контента через `/studio`.
2. Задеплоить на Vercel, добавить переменные окружения (README.md, раздел «Деплой»).
3. Настроить вебхук для мгновенного обновления после публикации (README.md, раздел «Мгновенное обновление»).
4. Проверить на реальном телефоне — эмулятор не заменяет полностью.
